# JAGA Landing Page

## Concept
Interactive Healthcare Intelligence System.

Visual direction combines Sui Overflow's interactive,
editorial and experimental web experience with JAGA's
defense-grade intelligence interface.

## Sections

01 SYSTEM
Hero with 3D healthcare network, system telemetry,
JAGA identity and primary CTA.

02 THE PROBLEM
Explain that fraud emerges through relationships,
not isolated claims. Visualize Participants,
Doctors, Providers and Claims.

03 NETWORK
Full-width interactive 3D network visualization.
Users can hover, zoom and focus entities.

04 INTELLIGENCE
Four core stages:
DETECT → CONNECT → EXPLAIN → INVESTIGATE.

05 INVESTIGATION
Show JAGA investigation interface:
risk score, network graph, risk explanation,
claims, timeline and peer comparison.

06 SYSTEM READY
Minimal terminal-style closing section
with institutional CTA.

## Visual Language

Background: #0e112a
Surface: #161933
Primary: #35f2a0
Critical: #ff5c67
High: #ff9f43
Medium: #ffd166

Display: Plus Jakarta Sans
Body: Inter
Telemetry: JetBrains Mono

Use subtle technical grid, thin hairlines,
small-radius surfaces and restrained glow.

## Motion

Slow network movement.
Node pulse.
Relationship flow.
Scroll-based scene transitions.
Hover/focus interactions.
Telemetry count-up.

Motion must feel computational and controlled,
never playful or excessive.

## Core Principle

Sui Overflow's interactive storytelling
×
JAGA's network intelligence
×
Healthcare investigation.
